Fingerprint Lab

A browser fingerprinting demonstration. It runs the same primitives a tracking site runs — canvas, WebGL, audio, fonts, API surface — and then shows you exactly what came back and how much of it narrows you down. Everything you are about to read was computed inside this tab.

What happens here

  • Reads properties this browser makes available to any page
  • Renders to offscreen canvases and hashes the output
  • Measures glyph widths to detect installed fonts
  • Queries permission states without requesting them
  • Displays the result to you, in full

What never happens here

  • No fetch, XHR, beacon or WebSocket
  • No IP address — no server is ever contacted
  • No geolocation, camera, microphone or clipboard request
  • No cookies, no localStorage, no IndexedDB write
  • No keystroke or pointer tracking
  • No third-party resources — no fonts, scripts or images

Verify it yourself: open your browser's Network panel, then reload this page. The only requests are this document, the stylesheet and the script. Disconnect from the internet before reloading and it still works.

Device Info Report

A complete device-info report, organised by category. Every value is tagged by how it was obtained — client-side, withheld, permission required, or requires server. The last category is the honest half: those fields appear on device-info sites but cannot be detected from the browser.

Why this exists

Fingerprinting is not exotic. It is the ordinary consequence of a browser that describes the machine it is running on in enough detail to lay out a page nicely. Every signal below was volunteered to this page by your browser, without being asked, because rendering a page requires it. The engineering skill being demonstrated here is the same skill a tracking company uses — the difference is that this page shows you the answer instead of selling it.

If you want to reduce your own number, the levers are: a browser that resists fingerprinting (Brave, Tor Browser, Firefox with privacy.resistFingerprinting), a standard window size, a default time zone, a common font set, and no unusual extensions. Note how each of those costs you something in convenience — that trade is the actual research question.
